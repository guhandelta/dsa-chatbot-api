## Product direction

The intended v1 serves one student well while retaining a design that can scale: Language Fundamentals, DSA, and Design Patterns, with one AI tutor. Each offered route should have coherent lessons, practice, independent assessment, useful feedback, application or transfer, and honest progress. Students may express goals, assumptions, decisions, and requested path changes. Human tutors and AI Tutor+ are later releases. Framework-specific pathways, circuit programming, and commercial package/pricing decisions are deferred. See [the v1 contract](V1_LEARNING_PRODUCT_CONTRACT.md); its stronger mastery model is a target, not current behavior.

## Retrieval, graphs, caching, and observability

- **RAG / LangChain:** `app/services/knowledge_base.py` uses LangChain document/embedding/vector-store interfaces. Chroma is the local file-backed option; PGVector is configurable. Retrieval combines scoped local curriculum, vector results, and vetted reference material in `app/services/rag_pipeline.py`. LangChain chat models wrap OpenAI, Claude, and Gemini in `app/services/llm_router.py`; messages also support Study Room, mentor, understanding checks, and agentic retrieval experiments. Deterministic embeddings are an explicit development-only mode, not semantic retrieval.
- **LangGraph:** `app/graphs/practice.py` runs the interruptible practice state machine. `app/services/practice_checkpoints.py` persists checkpoints in the application database; the router owns billing and event writes so graph resumes do not repeat them. `app/services/chat_model_routing.py` uses a separate small graph to classify a request and select at most two configured provider attempts. Neither graph is a curriculum knowledge graph.
- **Prompt caching:** `PROMPT_CACHE_ENABLED=true` by default. `app/services/prompt_cache.py` puts stable instructions before dynamic retrieved text and marks Claude's stable system block with an ephemeral cache breakpoint. Usage metadata records cache reads and writes when providers return them. A marker alone does not guarantee a cache hit.
- **CAG:** `CAG_ENABLED=false` by default. `app/services/context_pack.py` can preload pinned, size-limited, learner-safe Python or JavaScript context packs into the stable prefix, for Claude by default. Question-specific RAG remains active. A six-call broad-pack pilot was more expensive than its short baseline even with a warm cache; compact v2 packs have not had a live quality/cost comparison. See [CAG/KAG note](CAG_KAG_IMPLEMENTATION_NOTE.md) and [prompt-cache guide](PROMPT_CACHING_CAG.md).
- **KAG:** `KAG_ENABLED=false` by default. A small acyclic prerequisite pilot covers shared language stages 1–8 (`data/curriculum/prerequisite-pilot.json`). In focused language chat and Study Room Explain, relevant links can add at most two same-language learner-safe prerequisite lessons and optional guidance. It does not unlock content, score assessments, or grant mastery. Graph links require educational review before expansion.
- **LangSmith:** no explicit SDK use, environment configuration, or export integration was found in the inspected repository. The app instead has its own request-scoped trace/span store, estimated cost accounting, and admin trace views (`app/services/tracing.py`). This repository check does not prove the absence of external runtime configuration.

## Open work, in dependency order

1. **Author and verify three native paths:** start with JavaScript, Java, and Python. Use the common learning-unit structure, but choose each language's concepts, data structures, order, idioms, projects, and assessments independently. Fill the Arrays choice/transfer gaps, then extend the evidence checker to each authored unit. Do not infer quality from item counts or generated text.
2. **Prove a complete vertical slice in each section:** a language unit, binary-search DSA route, and Strategy decision/implementation route, with independent transfer, counterexamples, recovery, and small applications. Preserve the distinction between guided practice, passed assessment, and mastery.
3. **Settle the evidence/mastery contract:** version tasks/rubrics, record assistance, add explicit independent transfer evidence, and migrate historical data without silently promoting old `complete` or `solved` records. Align API/UI labels and dashboard totals with the new states.
4. **Connect bounded personalization:** turn student path records and observed weak spots into versioned recommendations and review activities while keeping the default route recoverable. Keep the Assumption Ledger and Decision Log student-authored, separate from shared curriculum facts.
5. **Finish section access:** choose historical subscriber rights, audit every API/service/background access surface, enforce rights before retrieval and execution, test direct links and expiry, and only then design section-specific packages.
6. **Harden and measure the tutor:** section-specific prompt/response evaluations, correction handling, factual grounding, uncertainty, answer safety, and an AI tutor operations dashboard that relates actions to outcomes and cost. The core tutor must be reliable before AI Tutor+.
7. **Evaluate augmentation on the same cases:** compare RAG only, KAG guidance, compact CAG, and useful pairings for teaching quality, latency, tokens, CPU/memory, and total provider cost. Do not enable either opt-in flag based solely on structural tests. Further live provider calls require a separately scoped prompt/data review and authorization.
8. **Complete release verification:** finish the per-language and combined walkthroughs, full API/UI/CI runs, migration and access checks, execution isolation checks, and instructional review of representative correct, incorrect, and ambiguous learner work. Record residual risks before paid launch.

The immediate operating rule is to finish each small slice, verify it, review the implementation and its user-facing claims, repair gaps, rerun relevant checks, and commit only the scoped changes. This document is a map of what exists and what remains, not a claim that the product is already ready to charge students.
