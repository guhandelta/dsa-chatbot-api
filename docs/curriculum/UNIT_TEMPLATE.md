## Teaching sequence

1. Mental model and when to use the concept.
2. A correct worked example with a trace and expected behavior.
3. A contrast example or common misconception.
4. A guided task with partially faded scaffolding.
5. A boundary, debugging or representation-choice task.
6. A fresh independent task.
7. An extension or composition connection.
8. An explicitly scheduled later review.

## Activity inventory

Repeat a row for every activity. Counts alone do not establish readiness.

| Stable activity ID | Family ID | Capability | Activity form | Depth step | Route | Prerequisites | Validation status |

| Fill in | Same underlying task variants share a family | Observable skill | trace / implement / debug / explain / design / integrate | understand / operate / boundaries / apply / justify / transfer | core / extension / scheduled review | Capability IDs | planned / drafted / validated / reviewed |

For each activity record:

- Learner-facing prompt, scope and allowed assumptions.
- Visible examples and any scaffolding supplied.
- Expected behavior and accepted alternatives in a private author section.
- Test fixtures and boundary cases where execution is supported.
- A private explanation of why any intentionally faulty code fails.
- Hint stages, including what information each reveals.
- Feedback mapped to a specific misconception.
- Evaluation rubric and what evidence is insufficient for a pass.
- Runtime and safety constraints for execution.
- Canonical problem/reference ID if another section uses this same activity.

## Review before publication

- Verify prerequisites, objective and activity alignment.
- Verify language/framework ownership of prose, code, fixtures and feedback.
- Reproduce authored outputs and intended failures in the declared environment.
- Verify public/private answer separation.
- Check that task families differ in what they test, not only surface wording.
- Confirm exact subscription scope and honest missing-content labels.
- Record version and reviewer; keep unpublished drafts out of the learner bank.
